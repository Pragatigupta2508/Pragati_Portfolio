## 🌌 About the Portfolio

This portfolio is designed to be more than just a resume on a webpage. It brings together my **technical projects, achievements, certifications, open-source contributions, creative work, and contact information** in an interactive galaxy-inspired interface.

The website features a **constellation/nebula aesthetic**, glassmorphism components, animations, responsive layouts, and interactive UI elements.

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/Pragatigupta2508/Pragati_Portfolio.git
```

Navigate into the project:

```bash
cd Pragati_Portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 🏗️ Production Build

To create an optimized production build:

```bash
npm run build
```

To run the production server:

```bash
npm start
```
